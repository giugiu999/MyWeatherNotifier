# Week 3 Resources

This document lists all helpful links, articles, and videos used to understand HTTP requests, REST APIs, and JSON handling in Python.

---

## **HTTP Requests in Python**
- **Official Requests Library Documentation**  
  https://requests.readthedocs.io/en/latest/  
  https://www.youtube.com/watch?v=hWyBeEF3CqQ
  *A comprehensive guide on using the requests library for making GET and POST requests, handling responses, and managing errors.*

- **Real Python – Python’s requests Library (Guide)**  
  https://realpython.com/python-requests/  
  *In-depth tutorial covering requests basics, headers, query parameters, and JSON parsing.*

---

## **JSON Handling**
- **Python JSON Module Documentation**  
  https://docs.python.org/3/library/json.html  
  *Official Python docs explaining how to parse and serialize JSON.*

- **W3Schools – Python JSON**  
  https://www.w3schools.com/python/python_json.asp  
  *A beginner-friendly introduction to loading, parsing, and working with JSON data in Python.*

## **OpenWeatherMap API**
- **OpenWeatherMap API Documentation**  
  https://openweathermap.org/current  
  *Official docs on current weather data API, parameters, and response formats.*

- **How to Get an API Key**  
  https://openweathermap.org/appid  
  *Step-by-step guide to signing up and obtaining a free API key.*

- **Video Tutorial – Python Weather App using OpenWeatherMap**  
  https://www.youtube.com/watch?v=aQZzMJgPMqQ
  *A simple video walkthrough on how to fetch weather data using requests and OpenWeatherMap API.*
